# 📊 Excel Data Exploration & Analysis

## 📌 Project Overview

This project demonstrates my foundational **Data Analytics and Microsoft Excel skills** through the exploration and analysis of a product dataset.

The dataset contains information such as **Product ID, Product Name, Brand Name, Quantity, Category, and Price**. The project focuses on using Excel formulas and functions to summarize data, apply business logic, perform conditional analysis, and extract useful information from text fields.

## 🎯 Project Objectives

* Explore and summarize product data
* Perform basic statistical calculations
* Categorize products based on price
* Analyze data using conditional functions
* Extract structured information from Product IDs
* Build a clear and organized Excel analysis

## 🛠️ Excel Skills Demonstrated

### 🔹 Data Summarization

Used:

* `SUM`
* `COUNT`
* `AVERAGE`

These functions were used to calculate the total price, number of products, and average product price.

### 🔹 Statistical Analysis

Used:

* `MIN`
* `MAX`

These functions were used to identify the minimum and maximum product prices.

### 🔹 Logical Analysis

Used the `IF` function to create a **Price Range** classification:

* Price ≥ $500 → **High Price**
* Price < $500 → **Standard Price**

### 🔹 Conditional Analysis

Used:

* `SUMIF`
* `COUNTIF`

These functions were used to analyze products within specific conditions, including calculating the total price of products in the Electronics category and counting products priced below $100.

### 🔹 Text Manipulation

Used:

* `LEFT`
* `RIGHT`
* `MID`

These functions were applied to the Product ID to extract:

* **Day**
* **Country Code**
* **Month**
